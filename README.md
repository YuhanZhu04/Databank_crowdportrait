# 天猫人群画像自动化分析工具  

## 项目简介  
本项目实现天猫策略中心与数据银行人群画像全流程自动化，通过逆向底层 API、提取浏览器 Cookie 实现静默鉴权，监听 WSS 加密通道获取用户画像数据，破解前端数据脱敏限制，并自动生成结构化 Excel 报表，将数小时人工流程缩短至秒级，高效支持多品牌受众分析。

## 技术栈 | Tech Stack
- Python
- API Reverse Engineering
- WebSocket (WSS)
- Cookie Authentication
- Pandas
- Excel Automation

## 核心功能 
- 静默登录与 Cookie 自动提取  
- WSS 加密通道监听与画像数据解析  
- 数据脱敏破解与真实覆盖人数还原  
- 多品牌自动化报表输出
  
# Tmall Audience Analysis Automation

## Introduction  
This project automates the entire workflow of audience analysis for Tmall Strategy Center and Data Bank. It reverse-engineers underlying APIs, extracts browser cookies for silent login, monitors WSS encrypted channels to capture user portrait data, breaks through platform data desensitization, and automatically generates structured Excel reports, reducing manual processing from hours to seconds for efficient multi-brand analysis.
## Core Features
- Silent login & automatic cookie extraction
- WSS encrypted channel monitoring & portrait data parsing
- Desensitization bypass & real coverage calculation
- Multi-brand automated report generation
